# 个人工作档案

用于在不同 AI 助手之间共享个人工作背景、设计要求、工作习惯和项目规范，减少重复沟通，提高设计效率与交付质量。

## 一、个人简介与工作背景

- **所属行业：** 灭蚊、驱蚊、灭蝇及相关害虫防制产品。
- **目标市场：** 面向各类消费群体，重点关注欧美市场的产品展示与营销需求。
- **核心工作内容：**
  - 亚马逊产品主图与副图设计
  - 亚马逊 A+ 详情页设计
  - 产品包装设计
  - Instagram、Facebook、Pinterest 等社交媒体宣传图设计
- **工作目标：** 通过专业、真实、统一的视觉设计，提升产品展示质量、品牌形象和营销转化效果。

## 二、工作习惯与设计原则

### 2.1 产品外观保真

- 严格保留参考图中产品的原始结构、外形比例、颜色、材质、按钮、格栅、接口等细节。
- 以用户提供的产品参考图作为主要依据，不随意重新设计产品。
- 不得擅自改变产品结构、配色、透视关系或配件数量。
- 修改现有图片时，只调整用户明确要求修改的部分，其他内容尽可能保持不变。
- 当生成效果与真实产品不一致时，应优先修正产品，而不是迁就场景效果。

### 2.2 写实产品摄影

- 优先采用真实商业摄影风格，避免明显的 AI 生成痕迹。
- 材质、光影、反射、阴影和透视应符合真实物理规律。
- 产品应清晰突出，避免广角畸变、过度曝光、材质发灰、阴影面积过大等问题。
- 白色产品应呈现干净、明亮、有质感的高级白，不能整体灰暗或失去细节。
- 场景应符合产品实际使用环境，人物动作、产品握持方式和使用逻辑应合理。
- 同一组图片应保持产品外观、人物形象、拍摄角度和整体视觉风格一致。

### 2.3 高效工作流程

- 开始设计前，先明确设计目标、目标人群、使用平台、图片尺寸和关键限制。
- 优先使用清晰、简洁、可复用的提示词和设计规范。
- 根据具体反馈逐项修改，不随意改变已经确认的设计内容。
- 系列图片应保持统一的配色、字体、构图、光影和信息层级。
- 尽量一次性明确产品要求、文案、画面构成和交付规格，减少反复修改。
- 交付前检查产品细节、文案拼写、图片尺寸、排版和整体一致性。

### 2.4 需求执行与准确性

- 严格遵守指定的尺寸、比例、颜色代码、产品数量、文案和品牌规范。
- 不添加用户未要求的文字、图标、装饰元素或配件。
- 不擅自修改已经确认的设计方案。
- 对不明确的关键要求，先提出问题确认，不凭空假设。
- 对最终效果进行检查，确保图片能够满足实际电商展示或营销使用需求。

## 三、沟通风格偏好

- **主要沟通语言：** 中文。
- **营销文案语言：** 面向欧美市场的图片和包装，按实际需求使用准确、自然的英文。
- **表达风格：** 直接、清晰、专业、实用，避免冗长的理论说明。
- **偏好的输出形式：** 对比表格、分步骤操作说明、检查清单、可直接使用的提示词和设计方案。
- **修改建议：** 指出具体问题，并给出明确的修改方法。
- **执行要求：** 优先按照已提供的参考图和明确要求执行，不随意发挥。
- **方案选择：** 需要比较多个方案时，说明各方案的优缺点，并给出明确推荐。
- **信息准确性：** 区分已确认的信息与推测内容，不夸大设计效果或产品功能。

## 四、设计任务与视觉规范

### 4.1 亚马逊产品主图与副图

- **主图设计：** 按亚马逊对应类目的主图政策执行；通常采用纯白背景，突出产品本身，并呈现合理的自然阴影。
- **副图设计：** 通过功能展示、尺寸说明、使用场景、产品细节和包装清单等内容，帮助消费者理解产品。
- **产品保真：** 产品外观必须与实际产品及参考图一致。
- **场景设计：** 场景应真实可信，人物动作自然，产品使用方式符合实际情况。
- **信息排版：** 主标题、卖点、辅助说明应有清晰的视觉层级，避免文字过多或画面拥挤。
- **交付检查：** 检查图片尺寸、产品细节、文字准确性和平台规范。

### 4.2 亚马逊 A+ 详情页

- 根据产品特点规划多个横向模块，形成完整、连贯的产品介绍。
- 通过主标题、辅助文案、产品图片和功能展示建立清晰的信息层级。
- 所有模块应保持统一的品牌色、字体、留白、排版和视觉风格。
- 重点展示产品优势、使用场景、功能细节和消费者关注的问题。
- 根据实际要求设置图片尺寸，确保文字清晰、画面完整。
- 避免模块之间风格不统一、信息重复、文字拥挤或重点不突出。
- 交付前检查全部模块的尺寸、文案和整体连贯性。

### 4.3 产品包装设计

- 面向欧美市场，兼顾品牌形象、产品识别度和商业展示效果。
- 严格保留产品真实外观，不以包装效果图代替真实产品结构。
- 统一品牌颜色、字体、图标、信息层级和视觉语言。
- 优先保证产品名称、核心卖点、规格、数量和必要警示信息清晰易读。
- 根据品牌定位合理控制装饰元素和留白，避免画面杂乱。
- 严格遵守指定的包装盒型、展开尺寸、印刷要求和各面板内容。
- 包装正面、背面、侧面应保持统一的视觉系统。
- 交付时区分包装设计效果图与可用于生产的印刷文件。

### 4.4 产品社交媒体宣传图

- **主要平台：** Instagram、Facebook、Pinterest。
- 根据平台特点、目标人群和宣传目的调整构图、比例和文案。
- 通过真实使用场景、清晰的产品展示和简洁的卖点传递产品价值。
- 保持品牌识别度，确保不同平台的宣传图片风格一致。
- 兼顾视觉吸引力、产品真实性和信息可读性。
- 避免夸大产品功效、误导性展示和过度堆砌文字。
- 建立可复用的宣传模板，便于新品推广、节日营销、功能介绍和品牌宣传。

## 五、项目经验与交付要求

### 5.1 亚马逊产品图片项目

- **主要交付：** 主图、副图、功能卖点图、尺寸图、使用场景图、包装清单图。
- **核心要求：** 产品保真、真实摄影效果、信息清晰、视觉统一。
- **验收重点：** 产品细节准确，画面符合平台要求，消费者能够快速理解产品特点。

### 5.2 亚马逊 A+ 页面项目

- **主要交付：** 多模块横向详情图、产品功能展示图、品牌介绍图。
- **核心要求：** 模块统一、排版清晰、文案准确、内容连贯。
- **验收重点：** 全页面视觉一致，重点突出，图片尺寸符合要求。

### 5.3 产品包装项目

- **主要交付：** 包装概念方案、正面设计、完整面板设计、包装效果图。
- **核心要求：** 品牌统一、结构准确、信息完整、符合目标市场审美。
- **验收重点：** 包装结构与规格正确，必要文字齐全，设计满足后续生产要求。

### 5.4 产品社媒宣传项目

- **主要交付：** 社媒宣传图、产品推广图、营销活动图、系列视觉模板。
- **核心要求：** 品牌统一、视觉吸引力强、信息简洁、产品展示真实。
- **验收重点：** 图片符合平台使用场景，文案准确，能够清晰传达宣传重点。

### 5.5 项目资料记录规范

每个项目建议记录以下内容：

- 项目名称与设计目标
- 产品参考图及不可修改的细节
- 目标市场与目标消费者
- 品牌颜色、字体及其他视觉规范
- 图片尺寸、比例与交付格式
- 必须使用的文案、图标及产品配件
- 已确认的设计方案与修改记录
- 当前进度、待办事项及下一步计划

## 六、长期工作目标

- 建立统一的亚马逊图片、A+ 页面、包装和社媒宣传视觉体系。
- 提高产品图片的真实感、外观保真度和商业展示质量。
- 建立可复用的提示词、设计规范、文案模板和项目资料。
- 减少重复沟通与无效修改，提高整体交付效率。
- 让同一产品在不同图片、不同模块和不同营销平台中保持一致。
- 形成适用于灭蚊、驱蚊、灭蝇等产品的标准化视觉内容工作流程。

## 维护与隐私规范

- 当工作习惯、品牌要求或项目重点发生变化时，及时更新本档案。
- 将已确认的项目规范和可复用设计资料分类保存。
- 使用 GitHub Issues 记录待办事项、修改需求和项目进度。
- 不公开密码、API 密钥、客户隐私或未经授权的公司机密。
- 每次提交修改前，检查公开仓库中的内容是否适合对外展示。
